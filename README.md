# 🚢 Infosys Maritime AI

**Infosys Springboard Virtual Internship 7.0 | Batch 4**

An AI-powered maritime freight operations project developed as part of the Infosys Springboard Virtual Internship. This repository contains the work completed across multiple project milestones, documenting the development and integration of maritime AI capabilities.

## 📌 Project Overview

**Infosys Maritime AI** focuses on applying Artificial Intelligence, machine learning and software development to maritime freight operations.

The project, named **FreightQuote AI**, brings together freight-related tools and intelligent features to support operational analysis, pricing, route insights, carrier information and decision-making.
