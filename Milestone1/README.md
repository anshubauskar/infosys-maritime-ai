# Milestone 1: User Authentication Module

## Overview
This project implements a user authentication module as part of Infosys Springboard Internship 7.0, Batch 4.

## Objectives
- User signup and login
- JWT-based session management
- Forgot password using security questions and email OTP
- User dashboard with logout
- Admin dashboard to view registered users

## Technology Stack
- Python
- Streamlit
- Google Colab
- JWT
- Gmail SMTP
- ngrok

## Validation
The application will validate required fields, email format, password strength, and password confirmation.

## How to Run
The notebook will contain the setup instructions and code required to run the application.
